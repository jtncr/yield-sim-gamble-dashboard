# Gamble Farm Sim (Extreme Risk)

Public dashboard for Justin's **extreme-risk** farm-rotation paper-trading simulation, targeting about 500% APY with honest reward-token marks.

- No real funds, wallets, or transactions.
- Completely separate from the [low-risk](https://jtncr.github.io/yield-sim-dashboard/), [higher-risk](https://jtncr.github.io/yield-sim-highrisk-dashboard/), and [degen](https://jtncr.github.io/yield-sim-degen-dashboard/) books.
- Regenerated and pushed on every simulator `update` cycle.
- Live page: https://jtncr.github.io/yield-sim-gamble-dashboard/
